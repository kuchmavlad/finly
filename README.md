# Finly

Мобильный серверный пилот инвестиционного учёта: React Native, Expo SDK 57, TypeScript, Expo Router и Supabase. Целевая платформа — iPhone через Expo Go. Английский интерфейс, тёмная тема Monochrome.

## Контекст

Начните с [PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md), [требований](docs/REQUIREMENTS.md), AGENTS.md и [Git Flow](CONTRIBUTING.md).

## Запуск на Windows и iPhone

Настройте публичные параметры Supabase по [SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md) в игнорируемом .env.local. Облачные миграции текущего проекта уже применены.

```powershell
cd C:\Users\test\Documents\ChatGPT\finly
npm.cmd ci
npx.cmd expo login
npm.cmd start -- --go --clear
```

Войдите в тот же аккаунт Expo, что и на телефоне. Компьютер и iPhone должны быть в одной локальной сети. Отсканируйте QR-код камерой и откройте ссылку в Expo Go; разрешите доступ к локальной сети. Оставьте компьютер и терминал включёнными. Если прежний dev-сервер запущен, сначала остановите его.

## Что работает

- Email/password, регистрация с подтверждением email, Sign out в Settings.
- Создание и выбор серверных портфелей, All portfolios, понятное пустое состояние.
- Overview: записанные денежные остатки по исходным валютам, рассчитанные по всей истории.
- Activity: серверные пополнения/выводы, фильтры, страницы по 50 записей.
- Record cash movement: точные суммы, серверная валидация, защита повторного запроса и восстановление pending на native.

Серверные данные сохраняются между запусками. Demo-источник не подключён к интерфейсу. Holdings и Analytics показывают отсутствие реализованных данных: брокер, сделки, котировки, FX и инвестиционная доходность ещё не подключены. Денежный остаток не является полной оценкой инвестиционного портфеля.

## Проверки

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npx.cmd expo export --platform ios
```

Тесты покрывают денежную точность, SQL/RLS, курсорную историю, несколько пользователей, повторы и восстановление pending, ошибки storage/сети и запоздалые ответы. Старые demo-расчёты остаются отдельными тестовыми материалами.

[DEVICE_CHECKLIST.md](docs/DEVICE_CHECKLIST.md) описывает проверку текущей версии на iPhone и двух настоящих Auth-сессиях. Подтверждение прежней demo-версии не заменяет эту проверку. Web-превью запускается через npm.cmd run web и не заменяет устройство; web-сессия и pending живут только в памяти.

Платные сервисы и реальные брокерские счета не подключались. SMTP, восстановление пароля и резервное копирование перед реальным импортом остаются отдельными задачами. Ранее npm сообщал об уязвимостях дерева зависимостей; принудительные несовместимые обновления не применялись.
