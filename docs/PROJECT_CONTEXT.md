## Серверные вкладки — актуальный статус 15 октября

- Основные вкладки используют accountRepository и отдельный AccountStore на пользователя. Demo-данные не загружаются; старый asset-маршрут показывает недоступность актива.
- Выбор портфеля включает серверные портфели, All portfolios и Create portfolio. Создание также доступно из пустого состояния и Settings → Manage portfolios.
- Overview: Recorded cash balances отдельно по исходным валютам. Activity: сохранённые пополнения/выводы, фильтры и страницы по 50. /add-operation пишет на сервер; /account управляет портфелями через тот же store.
- Holdings/Analytics объясняют отсутствие активов/расчётов. Фиктивные FX, цены, результаты, demo-настройки и переключение USD/UAH убраны из пользовательского потока. Доходность по одним cash movements не рассчитывается.
- Миграция 20261015165100_server_portfolios применена через MCP: cash_balances считает numeric SUM по всей истории, cash_entries_page использует курсор (occurred_on, created_at, id). Денежные значения возвращаются строками. Write RPC, проверки остатков и RLS сохранены; прямой доступ к numeric не расширен.
- Pending хранится до отправки под ключом проекта/пользователя, сохраняет прежний формат, UUID и payload для безопасного повтора. Ошибки storage блокируют новую запись. Подтверждённые отказы валидации позволяют исправить ввод. Смена пользователя удаляет store; запоздалые ответы игнорируются.
