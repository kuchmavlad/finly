# Finly

Минимальный прототип React Native + Expo + TypeScript для проверки Expo Go на iPhone. Сейчас реализован только стартовый экран и кнопка Test connection. Финансовые экраны появятся после проверки на устройстве.

## Запуск на Windows

Установлен Node.js 24 LTS. Откройте новое окно PowerShell после установки Node.js.

```powershell
cd C:\Users\test\Documents\ChatGPT\finly
npm.cmd ci
npx.cmd expo login
npm.cmd start -- --go
```

Войдите в тот же аккаунт Expo, что и на телефоне. Вводите пароль только в терминале. Не сохраняйте учётные данные в проекте.

Компьютер и iPhone должны быть в одной локальной сети. Отсканируйте QR-код камерой iPhone и откройте его в Expo Go. Разрешите Expo Go доступ к локальной сети. Если Windows запросит сетевой доступ для Node.js, разрешите его для домашней частной сети. Оставьте терминал и компьютер включёнными. Для остановки сервера нажмите Ctrl+C.

Если команды не найдены, перезапустите терминал. Установленный Node.js находится в `C:\Program Files\nodejs`.

## Проверка на телефоне

1. Открывается тёмный экран с надписью FINLY / DEMO.
2. Нажатие Test connection меняет текст на Connection confirmed.
3. Нет ошибок Expo Go и обрезанного текста.

Это проверка запуска и взаимодействия. Она не проверяет подключение к финансовому серверу: такого сервера пока нет.

## Локальная проверка

```powershell
npm.cmd run typecheck
npx.cmd expo lint
npx.cmd expo install --check
npx.cmd expo export --platform ios
```

Экспорт проверяет сборку JavaScript, но не заменяет запуск на физическом iPhone.

Проверено 13 октября 2026: TypeScript, lint, совместимость версий через Expo CLI и экспорт iOS/Hermes прошли. Пользователь подтвердил запуск в Expo Go на физическом iPhone. При установке npm сообщил об уязвимостях в дереве зависимостей; автоматическое обновление с несовместимыми версиями не применялось.
