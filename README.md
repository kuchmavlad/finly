# Finly

Мобильный demo-прототип инвестиционного учёта: React Native, Expo SDK 57, TypeScript и Expo Router. Целевая платформа — iPhone через Expo Go. Английский интерфейс, спокойная тёмная тема.

## Контекст для нового чата

Начните с [текущего статуса](docs/PROJECT_CONTEXT.md), [исходных требований](docs/REQUIREMENTS.md), `AGENTS.md` и [Git Flow](CONTRIBUTING.md). Не повторяйте опрос по уже принятым решениям.

## Запуск на Windows и iPhone

Node.js 24 LTS установлен в `C:\Program Files\nodejs`. Откройте новое окно PowerShell:

```powershell
cd C:\Users\test\Documents\ChatGPT\finly
npm.cmd ci
npx.cmd expo login
npm.cmd start -- --go --clear
```

Войдите в тот же бесплатный аккаунт Expo, что и на телефоне. Пароль вводите только в терминале. Компьютер и телефон должны быть в одной локальной сети. Отсканируйте QR-код обычной камерой iPhone и откройте ссылку в Expo Go. Разрешите Expo Go доступ к локальной сети. При запросе Windows разрешите Node.js сетевой доступ в домашней частной сети.

Оставьте компьютер и терминал включёнными; Ctrl+C останавливает сервер. После перехода со стартового экрана на Expo Router обязательно перезапустите сервер с `--clear`. Если уже запущен прежний сервер, сначала остановите его.

Если `npm.cmd` не найден, перезапустите PowerShell или временно добавьте путь:

```powershell
$env:Path = 'C:\Program Files\nodejs;' + $env:Path
```

## Что работает

- Overview: текущая стоимость, результат и процентный график Demo TWR с периодами 3M / 6M / YTD. Касание/ведение меняет результат и дату под Portfolio value; повторное касание выбранной точки возвращает текущий результат.
- Общий переключатель портфеля: IBKR, Inzhur, ОВГЗ, пустой портфель и All portfolios.
- USD/UAH; оригинальная валюта каждой операции сохраняется.
- Holdings: категории активов, позиции, остатки денег, карточки с данными облигаций.
- Activity: фильтры, demo-импорт и ручные записи; добавление пополнений, выводов, покупок, продаж, дивидендов, купонов и комиссий.
- Analytics: структура, реализованный/нереализованный результат, доход, комиссии и иллюстративное сравнение с S&P 500 TR.
- Settings: переключатели состояний данных и сброс demo-данных с подтверждением. Оформление — Monochrome, выбранное пользователем; временный переключатель удалён.

## Ограничения demo

Данные вымышлены и зафиксированы на 13 октября 2026. Курсы: 1 USD = 42 UAH. Биржевых запросов и сервера нет. Новые записи сохраняются только в памяти до перезагрузки приложения. Репозиторий данных отделён от экранов, чтобы позже заменить его API.

Суммы — целые minor units, операции округления используют BigInt. Покупки/продажи — только целые количества. Себестоимость — средняя; комиссии списываются отдельно. У облигаций есть номинал, clean price в процентах, НКД, купон и погашение; ввод сделки принимает полную сумму расчёта, включая НКД. Это упрощённые demo-правила, не утверждённая методика настоящего учёта.

Overview использует Demo TWR по синтетическим оценкам на даты операций: пополнения/выводы исключены из доходности, выплаты и комиссии учтены. Правила и ограничения — [DEMO_TWR.md](docs/DEMO_TWR.md). Кривые сравнения доходности — отдельная иллюстрация, не TWR, не реальные данные S&P 500; ручные операции их не меняют. XIRR показан как будущая функция. Налоги, корпоративные действия, переводы, FX-конвертации, реальные импорты и аудит исправлений отложены.

## Проверка

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npx.cmd expo install --check
npx.cmd expo export --platform ios
```

Тесты проверяют точность ввода, сверку demo-баланса, пополнения без прибыли, продажи и себестоимость, лимиты денег/количества, исторические операции, облигации, отсутствие цены, историю и сброс данных.

Для дополнительной проверки в браузере: `npm.cmd run web`. Это вспомогательный просмотр React Native Web, не PWA и не замена проверки на iPhone.

Подробный сценарий ручной проверки — [DEVICE_CHECKLIST.md](docs/DEVICE_CHECKLIST.md). 14 октября 2026 пользователь подтвердил предыдущую версию после исправления предупреждений Analytics. Новые палитры, жесты графиков и VoiceOver ещё требуют проверки на физическом iPhone.

При установке npm сообщил о 28 уязвимостях зависимостей (10 moderate, 18 high). Анализ и безопасное обновление остаются отдельной задачей; принудительные несовместимые обновления не применялись.
