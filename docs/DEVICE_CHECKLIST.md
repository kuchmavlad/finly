# Проверка demo-прототипа на iPhone

Запустить по README с `--go --clear` после установки зависимостей. Все суммы ниже относятся к исходному набору, без ручных изменений.

1. Overview / All portfolios / USD: стоимость $33,789.33; прибыль +$3,479.81; виден Demo. Переключить 3M, 6M, YTD — график меняет период.
2. Переключить USD → UAH, затем по очереди IBKR, Inzhur и Ukrainian bonds. Выбор сохраняется между вкладками.
3. Holdings: шесть позиций в общем портфеле, BND с отрицательным результатом, отдельные остатки USD/UAH. Проверить фильтры.
4. Открыть UST 2028: 2 облигации, номинал $1,000, clean price 99.20%, НКД $8.80, полная стоимость одной $1,000.80. Проверить карточку ОВГЗ и дату оценки Inzhur.
5. Activity: фильтры All / Trades / Income / Cash; исходные валюты; разные метки Demo import и Manual.
6. Добавить Deposit / IBKR / USD / 100 / 2026-10-13. В истории появляется одна новая запись. Стоимость IBKR увеличивается на $100, прибыль не меняется. Нажатие Save несколько раз не создаёт дубли.
7. Попытаться продать 3 UST при остатке 2, вывести сумму сверх денег, ввести 2026-02-30 и дробное число units. Должны появиться понятные ошибки, без новых записей.
8. Analytics: доли суммируются примерно в 100% с учётом округления. Показаны realized/unrealized/income/fees, отдельно — Sample comparison и будущий XIRR.
9. Settings: проверить Loading / Error с возвратом через Reload / Try again; Old prices; Missing prices с частичной стоимостью и скрытыми общими profit/allocation. Normal возвращает обычный вид.
10. Выбрать New portfolio — пустое состояние. Добавить пополнение и проверить денежный остаток.
11. Settings → Reset demo: сначала отменить, затем подтвердить. Восстанавливаются исходные данные. Полная перезагрузка приложения также сбрасывает ручные demo-записи.
12. Проверить safe areas, прокрутку, клавиатуру формы, возврат из модальных экранов и читаемость длинных UAH-сумм на iPhone 11.

Browser QA и экспорт iOS не подтверждают работу клавиатуры, native safe areas и всех экранов в Expo Go на устройстве. Отмечать проверку на телефоне только после ответа пользователя.
