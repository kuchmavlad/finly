# Контекст Finly для продолжения в новом чате

Обновлено: 15 октября 2026. Перед работой проверьте `git status`, текущую ветку и фактическое состояние PR: этот файл не заменяет Git.

## Принятые решения

- Полный исходный бриф: `docs/REQUIREMENTS.md`. Он сохраняет решения предварительного обсуждения.
- Личный инвестиционный учёт с будущей публикацией в App Store; сейчас только demo-прототип с нулевым бюджетом.
- React Native + Expo + TypeScript, iPhone, английский интерфейс, спокойная тёмная тема.
- Windows — основная среда. Node.js 24.20.0 установлен. iPhone 11, пользователь подтвердил iOS 27 и установку Expo Go, вход в аккаунт.
- 14 октября пользователь подтвердил проверку обновлённых экранов после исправления Analytics на iPhone: всё работает.
- Реальные счета, платные сервисы, публикация и backend в текущий этап не входят. Серверное хранение для будущей версии выбрано; конкретный сервис не выбран.
- Активы: акции, ETF, отдельные облигации, украинские ОВГЗ и сертификаты Inzhur. Бытовые расходы и физическая недвижимость исключены.
- Портфели по месту хранения, общий итог и переключение USD/UAH. Исходные валюты операций сохранять.
- IBKR: будущий ежедневный серверный импорт, полная история может потребовать архивных отчётов. Flex ещё не проверен.
- Настоящие XIRR/TWR, источник индекса, котировок, FX, налоги, комиссии, корпоративные действия и себестоимость нужно специфицировать отдельно. Demo-правила не считать утверждённой финансовой методикой.

## Текущая реализация

- `src/app`: Expo Router, четыре вкладки, карточка актива, форма добавления операции, настройки.
- `src/domain`: типы, расчёт demo-позиций, integer-money операции, валидация и синтетическая история.
- `src/data/demo.ts`: исходный набор и заменяемый интерфейс репозитория.
- `src/state`: выбранный портфель/валюта и состояние источника данных.
- `src/ui`: общие компоненты, ThemeProvider с единственной выбранной пользователем палитрой Monochrome, форматирование и интерактивный SVG-график. Прибыль/убыток отделены от акцента темы.
- `tests`: инварианты demo-учёта, шкалы/даты/выбор точек графика, исключение внешних потоков из Demo TWR.
- Demo-операции живут в памяти до перезагрузки. Настоящей базы и импорта нет. Не выдавать прототип за production-ready продукт.
- Demo-дата зафиксирована на 2026-10-13. Сравнение с индексом — явно подписанные иллюстративные кривые; XIRR пока не вычисляется.
- 14 октября: прошли 10 тестов, TypeScript, lint, проверка совместимости Expo и экспорт iOS. В браузере проверены главный экран на ширине iPhone 11, вкладки, USD/UAH, выбор портфеля, карточка облигации, запрет oversell, сохранение пополнения, аналитика, missing/error/empty states и сброс.
- При установке npm сообщил о 28 уязвимостях в дереве зависимостей (10 moderate, 18 high). Они ещё не разобраны; force-upgrade не применялся. Reanimated/Worklets закреплены в версиях из Expo SDK 57.

2. Проверить незакоммиченные изменения и PR текущей ветки; не перезаписывать чужую работу.
3. Выполнить typecheck, lint, тесты и iOS export при изменениях поведения.

5. Пользователь выбрал Monochrome; переключатель и остальные палитры удалены. Далее перейти к отдельным этапам из брифа: проверка IBKR, инфраструктура, история и финансовая методика.
