# Demo TWR: правила прототипа

Это расчёт по вымышленным ценам, не подтверждённая доходность реального счёта и не заявление о соответствии GIPS. Он добавлен по запросу показывать на Overview процент без скачков от пополнений и выводов.

- Для каждого инструмента используются прежние синтетические оценки на даты графика. На даты операций оценки линейно интерполируются между этими точками; для облигаций отдельно интерполируются clean price и НКД. Денежные оценки округляются до minor units.
- Операции обрабатываются по дате; внутри одной даты сохраняется порядок записей в demo-репозитории. Времени внутри дня пока нет. Каждая операция считается совершённой по синтетической оценке этой даты.
- Изменения стоимости связываются геометрически: новый коэффициент = предыдущий коэффициент × стоимость в конце интервала / стоимость в начале интервала. Доходность = (коэффициент − 1) × 100%.
- Перед каждым пополнением/выводом фиксируется стоимость; сам внешний поток не меняет коэффициент. После потока новая стоимость становится базой следующего интервала. Покупки, продажи, дивиденды, купоны и комиссии являются внутренними операциями и влияют на результат.
- Первая положительная сумма вложений начинает историю. До неё процент недоступен. Пустой интервал с нулевым капиталом нейтрален; доход без капитала, отрицательная оценка или отсутствующая цена удерживаемого актива делают дальнейшую доходность недоступной. После полного вывода сохраняется накопленный коэффициент; новые вложения продолжают его. Полная инвестиционная потеря даёт −100%.
- USD/UAH используют прежний фиксированный demo FX, поэтому проценты могут различаться лишь из-за округления minor units.
- 3M / 6M / YTD меняют видимый отрезок, но не обнуляют накопленную доходность: показатели подписаны Since inception. В выбранной точке Overview показывает исторические прибыль в деньгах и TWR; верхняя Portfolio value остаётся текущей.
- Analytics пока сохраняет отдельные SAMPLE-кривые портфеля и индекса. Это иллюстрация сравнения, не рассчитанный Demo TWR из Overview. XIRR, реальный индекс, налоги, корпоративные действия и производственная методика остаются отдельными задачами.

Принцип оценки на внешних денежных потоках и геометрического связывания: [GIPS Standards Handbook for Firms](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/). Источник описывает методический принцип; конкретные синтетические цены и порядок операций выше — соглашения этого прототипа.
